# Custom Invoice View Bundle

A Kimai plugin that provides a Harvest-like invoice overview dashboard.

## Features

- Interactive bar chart showing paid vs pending invoices by month
- Year switcher to view historical data
- Total paid and pending amounts for the selected year
- Invoice list with status indicators
- Responsive design matching Kimai's UI theme

## Usage

Access the invoice overview at: `/invoice-overview`

## Technologies

- Chart.js for data visualization
- Vue.js for interactive UI
- Doctrine ORM for database queries
